# Infinite Arch Leica Looks v1.2

Nine Looks: Invitation, Witness, Zone, Presence, Threshold, American Negative, Kin, Natura, Ember.

Run ia_final9_upload_pyto.py in Pyto to install all nine by default. It is self-contained. Join camera Wi-Fi, connect using FOTOS, then force-quit FOTOS while remaining connected. The folder uploader.py is also included; keep its folder intact. Both support --list for offline validation.

Only slot 1007 changed, from IA 400H to IA Kin. Eight other Looks are preserved from v1.1. IDs 1001–1009 and the known-working protocol remain intact. Kin_Comparisons includes the Agfa alternative and an actual LUT comparison sheet. The alternative is not installed by default. See CHANGELOG_v1.2.md for sources and limitations. v1.1 remains available for rollback.
