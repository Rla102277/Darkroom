# Infinite Arch Leica Looks v2.3.1 — icons only

Cubes, IDs, names, base and installers are byte-identical in behavior to v2.3 (camera-verified at ISO 400 on 2026-09-30). Only the 180x90 1-bit icons changed, to Leica's own convention as captured from FOTOS: two lines of large condensed capitals, "IA" over a three-letter code, with the code inverted (white in a black box) on the three B&W Looks exactly as Leica does for Blue, Selenium and Greg Williams.

INV Invitation, WIT Witness, VLT Vault (inverted); PRS Presence, THR Threshold, EMB Ember, SNC Sanctuary, KIN Kin, AFG Afterglow.

Install with ia_reload9_pyto.py (removes the v2.3 nine by record marker, installs these, sets Sharpness +1). Icons are stored per Look on the camera, so a reinstall is required to see them; cubes re-upload byte-identical.
