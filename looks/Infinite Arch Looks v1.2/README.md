# Infinite Arch Looks v1.2

The nine Leica Looks as shipped on the Q3 (Infinite_Arch_Leica_Looks_v1.2, the authoritative
release; 17-point cubes, IDs 1001 to 1009). Darkroom installs this folder into the Profile
browser on first run, as the group "Infinite Arch Looks v1.2", applied with the Amount slider.

Invitation, Witness, Zone were built on the Monochrome base in v1.2; in Darkroom they run on the
color image and convert inside the cube. v2.1 (Vault, Sanctuary, Afterglow and the rebuilds)
replaces this folder when its cubes arrive.
