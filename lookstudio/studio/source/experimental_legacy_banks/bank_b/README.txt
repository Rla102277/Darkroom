BEFORE RUNNING
  1. Back up camera settings.
  2. In FOTOS, remove EVERY downloaded Look. Leave only Standard, Monochrome,
     and Pure. The installer refuses to start if another downloaded Look remains.
  3. Keep upload_all.py, bank_config.py, and the looks folder together.

INSTALL
  1. Connect completely through FOTOS.
  2. Force-quit FOTOS while staying on Q3 Wi-Fi.
  3. Run upload_all.py in Pyto.
  4. Type: go
  5. Leave Pyto open. Each Look is written once and verified before the next.

If the camera ends the inherited session between Looks, reconnect through FOTOS
and run upload_all.py with go again. It safely resumes from the live table.

Do not mix Bank A and Bank B. Remove all downloaded Looks before switching banks.
