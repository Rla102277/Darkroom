---
name: iPhone camera installation
description: The required device flow for installing generated Leica Looks.
---

Leica Look installation is performed entirely on an iPhone: download and extract the package, open the injector in an iPhone Python interpreter, connect to the camera in Leica FOTOS, switch back to the interpreter without disconnecting, and run or play the script.

**Why:** The established user workflow does not use a computer. FOTOS creates the camera connection on the same iPhone that subsequently runs the injector.

**How to apply:** Keep website guides and package documentation phone-specific. Do not tell users to prepare a computer, move the computer onto the camera network, or force-close FOTOS unless later camera testing establishes a different requirement.
